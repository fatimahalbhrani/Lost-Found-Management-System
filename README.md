# Lost-Found-Management-System
This project is a database-driven system designed to help manage lost and found items within a university environment.

The system provides an organized way to report, track, search, and manage lost items through a structured database and a user-friendly graphical interface.

Problem Statement

Managing lost and found items manually can be inefficient and time-consuming. Information may become fragmented, making it difficult to track reported items and connect owners with their belongings.

The purpose of this project is to develop a digital solution that improves the management and retrieval of lost items through a centralized database system.

Project Objectives
Simplify the reporting of lost and found items.
Organize item information within a structured database.
Improve item tracking and retrieval processes.
Provide an easy-to-use graphical user interface.
Support efficient data management and querying.
